# Мастерская сувениров 4.0

Новый дизайн сайта: «МЕРЧ», мужчина со спины, отдельные PNG с морскими принтами, тени и короткая анимация выхода надписи из принта.

**Работаем в `infecto2014-ai/msuvenirov4.0`. Данные для сайта берём из `infecto2014-ai/msuvenirov3.0`.** Правила — в AGENTS.md; источник 3.0 используем только на чтение.

## Запуск и проверки

```sh
npm ci
npm run dev
npm test
npm run build
npm run check:links
```

Сайт 4.0 собираем заново по новой концепции. На главной реализованы навигация, «МЕРЧ», «На чём печатаем», «Наши работы», «Отзывы клиентов», «Почему выбирают нас», «Как заказать» и подвал. Данные о бизнесе берём из 3.0; его страницы и архитектура не являются заданием для 4.0.

Важно: в коде пока остаётся унаследованная основа 3.0. Её перенос был техническим начальным состоянием, а не сборкой нового сайта с нуля. При дальнейшей сборке оставляем необходимые элементы нового концепта и создаём остальные части заново.

Тестовая копия: https://infecto2014-ai.github.io/msuvenirov4.0/. Она закрыта от индексации. Автоматический push после проверок относится к main этого репозитория. Рабочий сервер и отправка заявок требуют отдельного разрешения владельца.

Правила работы и выбор проверок по типу изменения — в [AGENTS.md](AGENTS.md), актуальное состояние нового дизайна — в [docs/RECOVERY.md](docs/RECOVERY.md). Старые планы и памятки 3.0 в документацию 4.0 не входят.
