# Ручная круговая галерея 4.0

1. В MerchWorks оставить шесть ссылок на реальные фотографии и расположить их по окружности после запуска JavaScript. Добавить две кнопки для последовательного просмотра.
2. В merch-works.ts связать поворот с перетаскиванием, свайпом и стрелками. GSAP отвечает за доводку до следующего кадра, ScrollTrigger — за небольшой поворот при прокрутке страницы. При уменьшенном движении доводка мгновенная.
3. Проверить полный оборот, открытие фото, клавиатуру, сенсорный свайп, вертикальную прокрутку и запасную ленту без JavaScript.
